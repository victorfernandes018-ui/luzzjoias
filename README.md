# Luzz Joias — site

Site da Luzz Joias: moissanites, prata e banho de ouro branco & amarelo.

## Como atualizar as peças da loja
1. Coloque as fotos novas na pasta `images/`.
2. Abra `admin.html` no navegador, cadastre ou edite as peças.
3. Clique em **Baixar products.js** e substitua o arquivo `products.js` do repositório.

O pedido da sacola é finalizado pelo WhatsApp. Para a mensagem chegar pronta, preencha o número em `products.js` (`whatsapp: "55..."`).
